# Chinthan K | Portfolio

Personal portfolio website with Home, Resume and Biodata pages.

## Files
- `index.html` - page structure and content
- `style.css` - styling
- `script.js` - page navigation
- `images/` - profile photo and background

## Run
Open `index.html` in a browser, or enable GitHub Pages (Settings > Pages > Deploy from branch > main / root).
